# Starry Habits Daily Maths · Grades 4–7

This bank contains 160 original questions in 32 five-question quests. It covers all 72 KICD mathematics sub-strands across Grades 4–7, with at least two exercises per sub-strand. Each grade starts with a coverage index that maps topics to question IDs. The bank is a draft for teacher review. Each topic has practice questions, and some individual learning outcomes within a topic still require additional exercises or interactive tasks such as drawing and measurement.

The Party Leader sets the Hero’s school grade. Serve questions from that grade, then use the skills the Hero has covered in class to sequence the sets. Save the grade and question version with each attempt so the history still makes sense after a grade change. In the app, show the question first, offer the hint for a retry, and show the working after the attempt. Where the prompt supplies the unit, the answer field can ask for the number only.
